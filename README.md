# City Energy Consumption Analysis & Prediction System

## 📊 Project Overview
This project analyzes city-wide electricity usage patterns and predicts next-day energy consumption using machine learning.

## 🧾 Dataset
- Generated synthetic dataset using NumPy & Pandas
- 365 days data for 5 zones
- Features:
  - Date
  - ZoneID
  - AvgTemperature
  - Humidity
  - SpecialEvent
  - EnergyConsumption

## 📈 Analysis
- Monthly energy trends
- Zone-wise consumption
- Correlation analysis

## 📊 Visualizations
- Line chart (monthly trends)
- Heatmap (correlation)
- Bar chart (event vs non-event)

## 🤖 Model
- Linear Regression
- Evaluated using MAE

## ▶️ How to Run
1. Open Jupyter Notebook
2. Run all cells
3. Enter input values
4. Get prediction output

## 🔮 Output
Predicts next-day energy consumption based on:
- Temperature
- Humidity
- Events
